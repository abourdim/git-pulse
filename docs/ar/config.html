يُنشأ تلقائياً عند أول تشغيل. قابل للتعديل يدوياً أو عبر واجهة الإعدادات.

تعدد الحسابات

إدارة عدة حسابات GitHub في ~/.gitpulse/accounts.json:

{
  "default": "شخصي",
  "accounts": {
    "شخصي": { "token": "ghp_xxx", "label": "حسابي" },
    "عمل": { "token": "ghp_yyy", "label": "المؤسسة" }
  }
}

الحفظ على جانب العميل (v3.0+)

واجهة الويب تستخدم حفظاً مزدوجاً للمظهر واللغة والوضع:

التخزينالمفاتيحالغرض
localStoragegp_theme, gp_language, gp_modeتطبيق فوري — بدون إعادة تحميل
config.jsonweb_theme, language, modeاحتياطي من الخادم

الوضع المحمول

  • GHM_CONFIG يشير إلى portable/config/ على USB
  • الإعدادات والحسابات والرموز تُخزّن على USB
  • لا يُكتب شيء على الجهاز المضيف
