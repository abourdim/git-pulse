الأسئلة الشائعة

عام

س: ما هو GitPulse؟
مدير مستودعات GitHub مع سطر أوامر (29 أمراً) وواجهة ويب (23 صفحة). يتيح لك إدارة وتحليل وتأمين وعرض جميع مستودعاتك من مكان واحد.
س: ما إصدار Python المطلوب؟
Python 3.8 أو أعلى. تم الاختبار على 3.8 و 3.9 و 3.10 و 3.11 و 3.12.
س: ما هي المتطلبات؟
فقط requests. المثبّت ينصبها تلقائياً. اختياري: openai لملخصات الذكاء الاصطناعي.
س: هل يعمل على ويندوز؟
نعم. عبر Git Bash أو MSYS2 أو WSL أو وضع USB المحمول (portable/run.bat).

الأمان والرموز

س: هل رمزي آمن؟
نعم. الرمز يُخزّن محلياً في ~/.gitpulse/config.json. لا يُرسل أبداً إلا لواجهة GitHub API.
س: ما الصلاحيات المطلوبة للرمز؟
repo (وصول كامل للمستودعات)، read:org (قراءة المنظمات)، read:user (قراءة الملف الشخصي).
س: ماذا يفعل ماسح الأسرار؟
يبحث في ملفات مستودعاتك عن أنماط مفاتيح API وكلمات المرور والرموز المكشوفة باستخدام التعبيرات المنتظمة.

العرض التجريبي

س: كيف يعمل وضع العرض التجريبي؟
يستخدم 17 مستودعاً تجريبياً مع بيانات واقعية محاكاة. لا استدعاءات API، لا رمز مطلوب.

واجهة الويب

س: كيف أشغّل واجهة الويب؟
python gitpulse.py --web أو gp --web. يفتح تلقائياً http://127.0.0.1:5000.
س: هل يمكنني تغيير المنفذ؟
نعم. غيّر "web_port" في config.json أو شغّل بـ --port 8080.
س: هل المظاهر تُحفظ؟
نعم. المظهر واللغة والوضع تُحفظ في localStorage للمتصفح وفي config.json للخادم.
س: كيف تعمل مساحة الملفات؟
اذهب إلى /repo/{الاسم}/files. شجرة الملفات يساراً، العارض/المحرر يميناً. تلوين الكود لـ 15+ لغة برمجة.

الحدود

س: ما حدود واجهة GitHub API؟
مع رمز: 5,000 طلب/ساعة. وضع العرض التجريبي لا يستهلك أي حصة.
