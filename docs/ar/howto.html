التشغيل الأول والإعداد

bash gitpulse.sh          # الخيار 2 = تثبيت
gp                        # تشغيل (الاختصار يُنشأ تلقائياً)
gp --web                  # تشغيل واجهة الويب

عند أول تشغيل، GitPulse يطلب رمز GitHub الخاص بك. الصقه واضغط Enter. الرمز يُحفظ في ~/.gitpulse/config.json.

تجربة العرض التجريبي

gp --demo                 # سطر الأوامر مع بيانات محاكاة
gp --web --demo           # واجهة الويب مع بيانات محاكاة

17 مستودعاً تجريبياً، لا رمز مطلوب. مثالي لاكتشاف الميزات.

عرض المستودعات والبحث

سطر الأوامر: شغّل GitPulse، اختر الخيار 1 (عرض) أو 2 (بحث).

الويب: اذهب إلى /repos. انقر على رؤوس الأعمدة للترتيب. استخدم شريط البحث للتصفية.

إنشاء مستودع

سطر الأوامر: الخيار 4 ← أدخل الاسم والوصف والرؤية.

الويب: صفحة المستودعات ← زر « + مستودع جديد » ← املأ النموذج ← إنشاء.

مساحة الملفات (IDE)

اذهب إلى /repo/{الاسم}/files لمتصفح ملفات كامل:

  • التصفح — شجرة ملفات قابلة للتوسيع على اليمين، انقر لعرض المحتوى
  • العرض — تلوين الكود لـ 15+ لغة برمجة مع أرقام الأسطر
  • التحرير — تعديل أي ملف وإيداع مباشر على GitHub
  • المعاينة — عرض Markdown مباشر مع عرض مقسم
  • جديد / رفع / حذف — إدارة كاملة للملفات
  • أدوات عبقرية — مولّد README، ماسح الأسرار، بحث الكود، متتبع المهام، معرض الصور

النسخ الاحتياطي لجميع المستودعات

سطر الأوامر: الخيار 10 ← يحفظ بيانات جميع المستودعات بصيغة JSON مؤرخ.

فحص صحة المستودعات

سطر الأوامر: الخيار 11 ← كل مستودع يحصل على تقييم بناءً على: README، رخصة، CI، مشاكل.

الويب: /health ← جدول بتقييمات ملونة وشارات.

كشف الأسرار المكشوفة

سطر الأوامر: الخيار 23 ← يمسح الملفات بحثاً عن أنماط مفاتيح API وكلمات المرور.

الويب: /danger أو في مساحة الملفات عبر زر 🔐 الأسرار.

تنظيف الفروع الميتة والمهام

سطر الأوامر: الخيار 24 ← يجد الفروع المدمجة/القديمة، الملفات الكبيرة، تعليقات TODO/FIXME.

الويب: /archaeology أو في مساحة الملفات عبر زر 📋 المهام.

رؤية أنماط الإيداعات

سطر الأوامر: الخيار 26 ← تحليل الساعات والأيام والسلاسل. تقييم الانتظام.

الويب: /rhythm ← رسوم بيانية تفاعلية.

تغيير المظهر

الويب: /settings ← انقر على دائرة المظهر. يُطبَّق فوراً.

سطر الأوامر: الخيار 29 (الإعدادات) ← المظهر ← اختر من 7 مظاهر.

المظاهر السبعة: المسجد، الأندلس، الحمراء، نور، رقش، صحراء، زهرة.

تغيير اللغة

الويب: /settings ← اختر English أو Français أو العربية. التغيير مباشر، بدون إعادة تحميل.

العربية تفعّل تلقائياً التخطيط من اليمين إلى اليسار (RTL).

الأوامر الصوتية

اذهب إلى /voice. انقر على الميكروفون. الأوامر المدعومة:

  • « أرني المستودعات » ← صفحة المستودعات
  • « افتح لوحة القيادة » ← صفحة Dashboard
  • « تحقق من الصحة » ← صفحة Health

يتطلب Chrome أو Edge (واجهة Web Speech).

وضع USB المحمول

  1. انسخ مجلد gitpulse/ إلى محرك USB
  2. (اختياري) أضف WinPython في portable/python/
  3. شغّل portable/run.bat (ويندوز) أو portable/run.sh (ماك/لينكس)

كل الإعدادات تبقى على USB. لا يُكتب شيء على الجهاز المضيف.
