مدير مستودعات GitHub الكامل — سطر الأوامر + واجهة الويب
بواسطة workshop-diy.org

البدء السريع

bash gitpulse.sh                    # التثبيت
python gitpulse.py                  # وضع سطر الأوامر
python gitpulse.py --web            # واجهة الويب
python gitpulse.py --demo           # العرض التجريبي (بدون token)
python gitpulse.py --web --demo     # عرض تجريبي للويب
