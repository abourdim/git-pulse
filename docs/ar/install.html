التثبيت

المتطلبات

  • Python 3.8+ (تم الاختبار على 3.8–3.12)
  • requests (يُثبَّت تلقائياً بواسطة المثبّت)
  • Token GitHub (انظر أدناه)

الخيار أ: المثبّت بخطوة واحدة (موصى به)

bash gitpulse.sh      # اختر الخيار 2 (تثبيت)

المثبّت يقوم بكل شيء في خطوة واحدة:

تحديث فهرس الحزم (Linux)
تثبيت Python 3.8+ إذا لم يكن موجوداً
تثبيت pip إذا لم يكن موجوداً
تثبيت git إذا لم يكن موجوداً
تثبيت requests عبر pip
نسخ جميع الملفات إلى ~/.gitpulse/
إنشاء اختصار gp تلقائياً في ~/.bashrc أو ~/.zshrc

بعد التثبيت: احذف مجلد الاستخراج — الاختصار gp يشير إلى ~/.gitpulse/gitpulse.sh ويعمل من أي مكان.

الخيار ب: التثبيت اليدوي

# 1. فك الضغط أو استنساخ gitpulse/
# 2. تثبيت المتطلبات
pip install requests

# 3. التشغيل
python gitpulse.py

الخيار ج: USB محمول (بدون تثبيت)

نسخ مجلد gitpulse/ إلى محرك USB
(اختياري) وضع WinPython في portable/python/
تشغيل portable/run.bat (ويندوز) أو portable/run.sh (ماك/لينكس)

Token GitHub

GitPulse يحتاج رمز وصول شخصي للوصول إلى مستودعاتك:

اذهب إلى github.com/settings/tokens
انقر « Generate new token (classic) »
اختر الصلاحيات: repo، read:org، read:user
انسخ الرمز (يبدأ بـ ghp_)
