التشغيل

python gitpulse.py --web             # عادي
python gitpulse.py --web --demo      # عرض تجريبي

الخادم: http://127.0.0.1:5000. يفتح المتصفح تلقائياً.

البنية

  • الخادم: web/server.py — Python http.server بدون متطلبات
  • الموجّه: web/router.py — توجيه URLs مع <param>
  • القوالب: web/templating.py — {{var}}، {{for}}، {{if}}، {{include}}
  • المسارات: web/routes/__init__.py — معالجات الصفحات و API
