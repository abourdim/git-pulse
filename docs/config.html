Configuration

Config File

Location: ~/.gitpulse/config.json

Created on first run. Permissions set to chmod 600.

{
  "token": "ghp_your_token_here",
  "mode": "advanced",
  "language": "en",
  "web_theme": "masjid",
  "web_port": 5000,
  "web_host": "127.0.0.1",
  "web_auto_open": true,
  "clone_directory": "~/repos",
  "commits_count": 10,
  "default_sort": "updated",
  "default_direction": "desc",
  "default_repo_type": "all"
}

Multi-Account File

Location: ~/.gitpulse/accounts.json

Created when you add your first account via CLI option 27.

{
  "active": "personal",
  "accounts": {
    "personal": {
      "token": "ghp_personal_token",
      "username": "my-username"
    },
    "work": {
      "token": "ghp_work_token",
      "username": "work-account"
    }
  }
}

File permissions: chmod 600. No limit on accounts.

Portable Mode Config

When running from USB via portable/run.bat or run.sh:

  • GHM_CONFIG is set to portable/config/ on the USB
  • Config, accounts, and tokens stored on the USB drive
  • Nothing written to the host machine

Client-Side Persistence (v3.0+)

The Web UI uses dual persistence for theme, language, and mode:

StorageKeysPurpose
localStoragegp_theme, gp_language, gp_mode, gp_sortInstant apply — no page reload, no flash
config.jsonweb_theme, language, modeServer-side fallback. Synced via POST /api/settings

localStorage takes priority. If cleared, falls back to server config.

Troubleshooting Config

ProblemSolution
Config not savingCheck write permissions: ls -la ~/.gitpulse/
Token not foundCheck cat ~/.gitpulse/config.json or echo $GITHUB_TOKEN
Port in useChange "web_port" to 8080 or another free port
Reset everythingrm -rf ~/.gitpulse/ then re-run (wizard will re-appear)
