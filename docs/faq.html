Frequently Asked Questions

General

Q: What is GitPulse?
A GitHub repository manager with a CLI (29 commands) and a Web UI (23 pages). It lets you manage, analyze, secure, and visualize all your GitHub repos from one place.
Q: What Python version do I need?
Python 3.8 or newer. Tested on 3.8, 3.9, 3.10, 3.11, and 3.12.
Q: What are the dependencies?
Only requests. Everything else is Python standard library. Optional: openai (only for AI summaries feature).
Q: Does it work on Windows?
Yes — MSYS2, Git Bash, WSL, and native Windows cmd/PowerShell all work. The portable mode uses run.bat for easy launch.
Q: Does it work on macOS?
Yes. Install Python 3.8+ via Homebrew or the official installer, then run normally.
Q: Can I use GitPulse without a GitHub account?
Yes — demo mode. Run python gitpulse.py --demo or click "Try Demo" in the web UI. 17 sample repos, all features work with mock data.
Q: Does it work offline?
Demo mode works fully offline. For real GitHub data, you need internet access to api.github.com.

Security & Privacy

Q: Is my token secure?
Stored in ~/.gitpulse/config.json with chmod 600 (owner-only read/write). Never sent anywhere except api.github.com. Never logged, cached, or shared. For higher security, use environment variables instead.
Q: Are my account tokens encrypted?
Not encrypted at rest, but protected by file permissions (chmod 600). For production environments, consider a secrets manager or environment variables.
Q: Does GitPulse modify my repos?
Only when you explicitly use write actions: create, delete, edit, timestamp shift, or release creation. Read-only operations (list, search, health, analytics, scan) never modify anything.
Q: Does the secret scanner upload my code?
No. It reads files via the GitHub API (your files are already on GitHub). Nothing is sent to any third party.
Q: What secrets can the Danger Zone detect?
14 patterns: GitHub tokens (ghp_, gho_), AWS access/secret keys, Slack tokens and webhooks, private keys (RSA/DSA/EC), generic API keys and passwords, Heroku API keys, Sendgrid keys, Twilio keys, Google API keys, Stripe live/test keys.
Q: Can I expose the web UI to the internet?
Not recommended. GitPulse has no authentication on the web UI — it's designed for local or LAN use. If you need remote access, put it behind a reverse proxy (Nginx, Caddy) with proper authentication.

Web UI

Q: Why does the web server not start?
Usually port 5000 is in use. Change it in ~/.gitpulse/config.json: "web_port": 8080. On macOS, AirPlay Receiver uses port 5000 by default.
Q: Why is Voice Control not working?
Voice requires Chrome or Edge. Firefox and Safari don't support the Web Speech API. On Chrome, it works on localhost without HTTPS.
Q: How do I change themes?
Settings page → select theme → Save. Or edit config: "web_theme": "andalus". Seven themes available — see Themes.
Q: Can I auto-start the web UI?
Add python /path/to/gitpulse.py --web to your startup scripts, cron (@reboot), systemd service, or Windows Task Scheduler.
Q: The web page is blank / broken
Check the terminal for Python errors. Clear browser cache. Try a different browser. Verify all template files exist in web/templates/.

Features

Q: What's the difference between Beginner and Advanced mode?
Beginner shows 8 safe items with friendly labels ("projects" instead of "repos"). Advanced shows all 29 commands with technical terminology. Dangerous features (delete, bulk ops) are hidden in beginner mode. Switch anytime from Settings.
Q: How many accounts can I add?
No limit. Each gets a label (e.g., "personal", "work", "client-x").
Q: Does switching accounts affect my local git config?
No. GitPulse only changes the API token for GitHub REST calls. Your local .gitconfig and SSH settings are untouched.
Q: Why do some analytics return empty data?
GitHub traffic API requires push access to the repo. If you're a collaborator without push access, traffic data won't be available.
Q: Does the AI summary require OpenAI?
The "Magic Diff Storyteller" uses pure pattern matching — no API needed. The "AI Summary" feature uses OpenAI's API (requires pip install openai and an API key). Both are in menu option 22.

Demo Mode

Q: Can I break anything in demo mode?
No. All data is fake and lives in memory. Creating or deleting repos only affects the current session. Everything resets on restart.
Q: Do analytics show real data in demo?
No. All numbers are randomly generated mock data. Real analytics require a connected GitHub account with push access.
Q: How do I exit demo mode and connect a real account?
Restart GitPulse without the --demo flag. In the web UI, go to /settings (when implemented) or restart the server.

Limits & Performance

Q: What's the GitHub API rate limit?
5,000 requests/hour for authenticated users. Most GitPulse operations use 1–5 requests. Heavy operations like health check (which checks every repo) or backup might use 50–200 requests depending on repo count.
Q: I got "rate limit exceeded" — what do I do?
Wait for the rate limit to reset (usually within an hour). Reduce scope of scans. Use cached/demo data while waiting.
Q: How many repos can GitPulse handle?
Tested with up to 200+ repos. The API returns paginated results (100 per page). Some features like health check may be slow with 100+ repos due to per-repo API calls.

Troubleshooting

Q: "No module named requests"
pip install requests or pip install requests --break-system-packages (on newer Python).
Q: "Permission denied" on config file
chmod 600 ~/.gitpulse/config.json
Q: "Address already in use"
Port 5000 is taken. Set "web_port": 8080 in ~/.gitpulse/config.json.
Q: Some features fail but token works
Check scopes at github.com/settings/tokens. Need: repo, read:user. Optional: delete_repo, workflow.
Q: Installer fails on MSYS2
Update MSYS2 first: pacman -Syu && pacman -S python python-pip, then re-run bash gitpulse.sh.
