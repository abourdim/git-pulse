Multi-compte

Gérez plusieurs comptes GitHub dans ~/.gitpulse/accounts.json :

{
  "default": "personnel",
  "accounts": {
    "personnel": { "token": "ghp_xxx", "label": "Mon GitHub" },
    "travail": { "token": "ghp_yyy", "label": "Organisation" }
  }
}

Basculez via la commande CLI #27 (Multi-compte) ou en modifiant le fichier.

Persistance côté client (v3.0+)

L'interface Web utilise une double persistance pour le thème, la langue et le mode :

StockageClésObjectif
localStoragegp_theme, gp_language, gp_mode, gp_sortApplication instantanée — pas de rechargement, pas de flash
config.jsonweb_theme, language, modeRepli côté serveur. Synchronisé via POST /api/settings

localStorage a la priorité. S'il est vidé, le repli utilise la config serveur.

Mode portable

En exécution depuis USB via portable/run.bat ou run.sh :

  • GHM_CONFIG pointe vers portable/config/ sur la clé USB
  • Config, comptes et tokens stockés sur la clé USB
  • Rien n'est écrit sur la machine hôte

Dépannage

ProblèmeSolution
Config ne sauvegarde pasVérifier les permissions : ls -la ~/.gitpulse/
Token non trouvéVérifier cat ~/.gitpulse/config.json ou echo $GITHUB_TOKEN
Port occupéChanger "web_port" à 8080 ou un autre port libre
Tout réinitialiserrm -rf ~/.gitpulse/ puis relancer (l'assistant réapparaîtra)
