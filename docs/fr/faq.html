Questions fréquentes

Général

Q : Qu'est-ce que GitPulse ?
Un gestionnaire de dépôts GitHub avec un CLI (29 commandes) et une interface Web (23 pages). Il permet de gérer, analyser, sécuriser et visualiser tous vos dépôts GitHub depuis un seul endroit.
Q : Quelle version de Python est nécessaire ?
Python 3.8 ou supérieur. Testé sur 3.8, 3.9, 3.10, 3.11 et 3.12.
Q : Quelles sont les dépendances ?
Uniquement requests. L'installeur l'installe automatiquement. Optionnel : openai pour les résumés IA.
Q : Est-ce que ça marche sur Windows ?
Oui. Via Git Bash, MSYS2, WSL, ou le mode portable USB (portable/run.bat).

Sécurité & Tokens

Q : Mon token est-il en sécurité ?
Oui. Le token est stocké localement dans ~/.gitpulse/config.json. Il n'est jamais envoyé ailleurs qu'à l'API GitHub. Le scanner de secrets ne signale jamais votre propre token.
Q : Quelles portées de token sont nécessaires ?
repo (accès complet aux dépôts), read:org (lire les organisations), read:user (lire le profil). Pour les actions GitHub : ajouter workflow.
Q : Que fait le scanner de secrets ?
Il recherche dans les fichiers de vos dépôts les clés API, mots de passe, tokens et secrets exposés en utilisant des expressions régulières. Il ne télécharge ni ne stocke aucun contenu de fichier.

Mode démo

Q : Comment fonctionne le mode démo ?
Il utilise 17 dépôts exemples générés avec des données simulées réalistes. Aucun appel API, aucun token nécessaire. Parfait pour explorer les fonctionnalités avant de connecter votre vrai compte.
Q : Puis-je modifier les données de démo ?
Les données de démo sont générées au démarrage par lib/demo.py. Vous pouvez modifier ce fichier pour personnaliser les dépôts exemples.

Interface Web

Q : Comment lancer l'interface web ?
python gitpulse.py --web ou gp --web. Ouvre automatiquement http://127.0.0.1:5000.
Q : Puis-je changer le port ?
Oui. Modifier "web_port" dans config.json ou lancer avec --port 8080.
Q : Les thèmes sont-ils persistants ?
Oui. Le thème, la langue et le mode sont sauvegardés dans localStorage du navigateur ET dans config.json côté serveur. Aucun flash au rechargement.
Q : Comment fonctionne l'espace de fichiers ?
Allez sur /repo/{nom}/files. Arbre de fichiers à gauche, visionneuse/éditeur à droite. Coloration syntaxique pour 15+ langages. Outils génie : génération README, scanner de secrets, recherche de code, suivi TODO, galerie d'images.

Limites

Q : Quelles sont les limites de l'API GitHub ?
Avec un token : 5 000 requêtes/heure. GitPulse affiche l'utilisation restante. Le mode démo ne consomme aucune limite.
Q : Combien de dépôts sont supportés ?
Aucune limite côté GitPulse. L'API GitHub pagine à 100 par requête — GitPulse gère automatiquement la pagination.
