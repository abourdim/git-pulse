Premier lancement & Configuration

bash gitpulse.sh          # Option 2 = Installer
gp                        # Lancer (l'alias est créé automatiquement)
gp --web                  # Lancer l'interface Web

Au premier lancement, GitPulse demande votre token GitHub. Collez-le et appuyez sur Entrée. Le token est sauvegardé dans ~/.gitpulse/config.json.

Essayer le mode démo

gp --demo                 # CLI avec données simulées
gp --web --demo           # Interface Web avec données simulées

17 dépôts exemples, aucun token nécessaire. Parfait pour découvrir les fonctionnalités.

Lister & Chercher les dépôts

CLI

# Lancer GitPulse, choisir option 1 (Lister) ou 2 (Chercher)
gp

Web

Aller sur /repos. Cliquer sur les en-têtes de colonnes pour trier. Utiliser la barre de recherche pour filtrer. Les préférences de tri sont sauvegardées.

Créer un dépôt

CLI : Option 4 → entrer le nom, la description, la visibilité.

Web : Page Dépôts → bouton « + Nouveau dépôt » → remplir le formulaire → Créer.

Espace de fichiers (IDE)

Aller sur /repo/{nom}/files pour un navigateur de fichiers complet :

  • Parcourir — arbre de fichiers extensible à gauche, cliquer pour voir le contenu
  • Voir — coloration syntaxique pour 15+ langages, numéros de lignes
  • Éditer — modifier n'importe quel fichier, commit direct sur GitHub
  • Aperçu — rendu Markdown en direct avec vue partagée
  • Nouveau / Téléverser / Supprimer — gestion complète des fichiers
  • Outils génie — générateur README, scanner de secrets, recherche de code, suivi TODO, galerie d'images, injecteur de modèles

Sauvegarder tous les dépôts

CLI : Option 10 → sauvegarde les métadonnées de tous les dépôts en JSON horodaté.

Vérifier la santé des dépôts

CLI : Option 11 → chaque dépôt reçoit un score basé sur : README, licence, CI, issues, description, taille.

Web : /health → tableau avec scores colorés et badges.

Détecter les secrets exposés

CLI : Option 23 → scanne les fichiers à la recherche de patterns de clés API, mots de passe, tokens.

Web : /danger → interface visuelle avec indicateurs de risque. Aussi disponible dans l'espace de fichiers via le bouton 🔐 Secrets.

Nettoyer les branches mortes & TODOs

CLI : Option 24 → trouve les branches fusionnées/obsolètes, gros fichiers, commentaires TODO/FIXME/HACK.

Web : /archaeology ou dans l'espace de fichiers via le bouton 📋 TODOs.

Catégoriser automatiquement les dépôts

CLI : Option 25 → classe les dépôts en 10 catégories (web, mobile, API, data, devops, etc.).

Web : /grouper

Voir vos schémas de commits

CLI : Option 26 → analyse les heures, jours, séquences de commits. Score de régularité.

Web : /rhythm → graphiques interactifs.

Voir l'analytique du trafic

CLI : Option 20 → vues, clones, référents, chemins populaires (14 derniers jours).

Web : /analytics

Basculer entre les comptes

CLI : Option 27 → ajouter, lister, basculer entre les tokens GitHub.

Fichier : ~/.gitpulse/accounts.json

Générer des résumés IA

CLI : Option 22 → nécessite une clé OpenAI dans la config ("openai_key").

Génère des résumés de dépôts et raconte les diffs de manière narrative.

Changer de thème

Interface Web

/settings → cliquer sur une pastille de thème. Appliqué instantanément.

CLI

Option 29 (Paramètres) → Thème → choisir parmi les 7 thèmes.

Les 7 thèmes : Masjid, Andalus, Al-Hamra, Nur, Raqsh, Sahra, Zahra.

Changer la langue

Web : /settings → sélectionner English, Français ou العربية. Changement en direct, pas de rechargement.

CLI : Option 29 → Langue.

L'arabe active automatiquement la mise en page RTL (droite à gauche).

Utiliser les commandes vocales

Aller sur /voice. Cliquer sur le microphone. Commandes supportées :

  • « montre-moi mes dépôts » → page Dépôts
  • « ouvre le tableau de bord » → page Dashboard
  • « vérifie la santé » → page Health

Nécessite Chrome ou Edge (API Web Speech).

Machine à remonter le temps

Aller sur /timemachine/{nom}. Utilisez le curseur pour naviguer dans les commits. L'arbre de fichiers se met à jour en temps réel pour montrer l'état du dépôt à chaque commit.

Mode USB portable

  1. Copier le dossier gitpulse/ sur une clé USB
  2. (Optionnel) Ajouter WinPython dans portable/python/
  3. Lancer portable/run.bat (Windows) ou portable/run.sh (Mac/Linux)

Toute la configuration reste sur la clé USB. Rien n'est écrit sur la machine hôte.
