Installation

Prérequis

  • Python 3.8+ (testé 3.8–3.12)
  • requests (installé automatiquement par l'installeur)
  • Token GitHub (voir ci-dessous)

Option A : Installeur en une étape (recommandé)

bash gitpulse.sh      # Sélectionner option 2 (Installer)

L'installeur fait tout en une étape :

Met à jour l'index des paquets (Linux)
Installe Python 3.8+ si absent
Installe pip si absent
Installe git si absent
Installe requests via pip
Copie tous les fichiers vers ~/.gitpulse/ (y compris le lanceur)
Crée automatiquement l'alias gp dans ~/.bashrc ou ~/.zshrc

Après l'installation : supprimez le dossier d'extraction — l'alias gp pointe vers ~/.gitpulse/gitpulse.sh et fonctionne partout.

Option B : Installation manuelle

# 1. Décompresser ou cloner gitpulse/
# 2. Installer la dépendance
pip install requests

# 3. Lancer
python gitpulse.py

Option C : USB portable (aucune installation)

Copier le dossier gitpulse/ sur une clé USB
(Optionnel) Mettre WinPython dans portable/python/ pour Windows sans installation
Lancer portable/run.bat (Windows) ou portable/run.sh (Mac/Linux)

Token GitHub

GitPulse a besoin d'un Personal Access Token pour accéder à vos dépôts :

Aller sur github.com/settings/tokens
Cliquer « Generate new token (classic) »
Sélectionner les portées : repo, read:org, read:user
Copier le token (commence par ghp_)
Coller dans GitPulse au premier lancement (ou via --token)

Vérifier l'installation

# Depuis n'importe quel répertoire :
gp

# Ou directement :
python ~/.gitpulse/gitpulse.py

# Mode Web :
gp --web

# Lancer l'installeur
bash gitpulse.sh
