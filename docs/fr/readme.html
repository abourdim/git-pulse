GitPulse v6.0 — Noor

Le gestionnaire complet de dépôts GitHub — CLI + Interface Web
Propulsé par workshop-diy.org

Démarrage rapide

bash gitpulse.sh                    # Installer
python gitpulse.py                  # Mode CLI
python gitpulse.py --web            # Interface Web
python gitpulse.py --demo           # Démo (sans token)
python gitpulse.py --web --demo     # Démo Web

Seule dépendance : requests — Python 3.8+
