Comment fonctionne l'i18n

  • Fichiers de traduction : web/static/i18n/{en,fr,ar}.json — 89 clés chacun
  • Script chargeur : web/static/js/i18n.js — charge automatiquement depuis localStorage sur chaque page
  • Balisage HTML : data-i18n="clé" sur les éléments, data-i18n-attr="placeholder" pour les champs de saisie
  • Changement en direct : changer la langue dans Paramètres s'applique instantanément (pas de rechargement)

Ajouter une nouvelle langue

  1. Copier web/static/i18n/en.json en xx.json
  2. Traduire les 89 valeurs
  3. Ajouter <option value="xx">Nom de la langue</option> dans settings.html
  4. Si RTL : ajouter val === "xx" à la vérification dir dans header.html et settings.html
