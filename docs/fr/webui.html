Interface Web

Lancement

python gitpulse.py --web             # Normal
python gitpulse.py --web --demo      # Démo (sans token)

Serveur : http://127.0.0.1:5000. Le navigateur s'ouvre automatiquement. Sans token ? La page d'accueil apparaît avec les boutons Connecter / Démo / Tutoriel.

Architecture

  • Serveur : web/server.py — Python http.server, zéro dépendance
  • Routeur : web/router.py — Dispatch d'URLs avec <param>
  • Modèles : web/templating.py — {{var}}, {{for}}, {{if}}, {{include}}
  • Routes : web/routes/__init__.py — gestionnaires de pages + API

Espace de fichiers (v2.0+)

Navigateur de fichiers complet de type IDE à /repo/{nom}/files :

  • Panneau arbre — arbre de dossiers extensible avec tailles, recherche par filtre
  • Visionneuse de code — coloration syntaxique pour 15+ langages
  • Éditeur — modifier n'importe quel fichier dans le navigateur, commit direct sur GitHub
  • Aperçu — Markdown rendu en direct, vue partagée (code + rendu)
  • Outils génie — générateur README, injecteur de modèles, suivi TODO, scanner de secrets, recherche de code, galerie d'images
  • Téléverser / Nouveau / Supprimer — gestion complète des fichiers

Internationalisation (i18n)

Système de traduction côté client introduit en v6.0 :

  • 3 langues : English, Français, العربية (avec support RTL complet)
  • 89 clés de traduction dans 8 modèles (74 éléments balisés)
  • Fichiers JSON : /static/i18n/en.json, fr.json, ar.json
  • Changement en direct : Paramètres → Langue applique instantanément (pas de rechargement)
