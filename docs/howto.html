First Run & Setup

Run python gitpulse.py
Choose language: English / Français / العربية
Choose mode: 🐣 Beginner (8 items, safe) or 🔥 Advanced (29 items)
Enter your GitHub token (ghp_...). Don't have one? Get a token or type demo
GitPulse authenticates and shows the main menu. Done!

Settings are saved to ~/.gitpulse/config.json — next launch skips the wizard.

Try Demo Mode

No GitHub account needed. Four ways to activate:

MethodCommand
CLI flagpython gitpulse.py --demo
Web flagpython gitpulse.py --web --demo
Token promptType demo instead of a token
Web UIClick ★ Try Demo Mode on the welcome page

17 sample repos with mock data for all features. Create/delete repos in-session (resets on restart).

List & Search Repos

CLI

Select option 1 (List repos)
Choose sort: updated / created / name
Choose filter: all / public / private
Repos displayed with 🔒/🌍 badges, language, stars, last push date

Search

Select option 2 (Search repos)
Enter search term — matches name, description, topics, language
Results shown instantly

Web

Go to /repos — browse with search bar at top. Click any repo for details.

Create a Repo

Select option 4
Enter repo name (e.g., my-new-project)
Enter description (optional)
Choose visibility: public or private
Auto-init with README? (Y/n)
Repo created on GitHub — URL shown

Edit a Repo

Change any repo setting — available in both CLI and Web UI.

CLI: Select option 6 (Edit repo) — Web: open /repo/{name} and click ✏️ Edit
Editable fields: name, description, visibility (public/private), topics, default branch, homepage URL, wiki (on/off), issues (on/off), archived (yes/no)
CLI: leave blank to keep current value — Web: modify fields and click Save Changes
Topics use a separate GitHub API — they are updated alongside other fields automatically

Note: Archiving a repo makes it read-only. Renaming a repo changes its URL.

Delete a Repo

⚠️ Permanent and irreversible. Hidden in beginner mode.

Select option 5 (advanced mode only)
Enter repo name
Confirm by typing the full repo name again
Repo permanently deleted from GitHub

Requires delete_repo scope on your token.

Back Up All Repos

Select option 10 (Backup manager)
Choose destination folder (default: ~/repos)
GitPulse clones every repo into that folder
Optional: compress to timestamped .zip

Web: go to /backup and click Backup.

Check Repo Health

Select option 11 (Health dashboard)
Every repo is scanned for 5 checks:
  • ✅ Has README.md
  • ✅ Has LICENSE
  • ✅ Has .gitignore
  • ✅ Has description
  • ✅ Has topics
Score 0–100% displayed per repo

Web: /health → click "Run Health Check" → see scores in a grid.

Bulk Operations

Advanced mode only (option 12).

  • Mass rename: rename multiple repos with a find/replace pattern
  • Visibility toggle: flip public↔private for selected repos
  • Bulk delete: delete multiple repos at once (triple-confirmed)
  • Topic management: add/remove topics across many repos

Find Leaked Secrets

Select option 23 (Danger zone)
Choose "Scan for leaked secrets"
Enter repo name
GitPulse scans up to 50 files for 14 secret patterns:
GitHub tokensghp_, gho_
AWS keysAccess keys, secret keys
SlackTokens (xox), webhooks
Private keysRSA, DSA, EC
API keysGeneric api_key= patterns
PasswordsGeneric secret=, password=
ServicesHeroku, Sendgrid, Twilio, Google, Stripe
Also checks risk indicators: missing .gitignore, public+no license, >500MB, unprotected branch

Web: /danger → enter repo name → click Scan.

Clean Up Dead Branches & TODOs

Select option 24 (Git archaeology)
Choose what to find:
  • Dead branches: no commits in 6+ months
  • Large files: files >1MB
  • TODOs: TODO, FIXME, HACK, XXX in code
  • Stale PRs: open PRs older than 90 days
  • Empty repos: repos with no content
Enter repo name → results displayed

Web: /archaeology → enter repo name → click Scan.

Auto-Categorize Repos

Select option 25 (Smart grouper)
Choose "Auto-group all repos"
GitPulse sorts every repo into one of 10 categories:
Web AppJS/TS/HTML, package.json, react/vue
MobileSwift/Kotlin/Dart, Podfile, build.gradle
IoT / HWC/C++, platformio.ini, .ino files
API / BackendGo/Rust/Java, Dockerfile
Librarysetup.py, Cargo.toml, library topics
Data / MLJupyter/R, .ipynb, ML topics
DevOpsShell/HCL, Jenkinsfile, terraform
Docsmkdocs.yml, docs/, documentation
Learningtutorial/course/learning topics
Tool / CLIcli.py, main.go, tool topics

Web: /grouper → click "Auto-Group".

See Your Coding Patterns

Select option 26 (Commit rhythm analyzer)
GitPulse fetches commits from your top 10 repos
Analysis shows:
  • Peak coding hour
  • Morning / Afternoon / Evening / Night percentages
  • Weekday distribution
  • Weekend coding percentage
  • Burst days (5+ commits in one day)
  • Bimodal pattern detection (code both morning AND evening)
Your style: 🦉 Night Owl, 🐦 Early Bird, 🌙 Evening Warrior, 🔄 Dual Mode, or ⚡ Steady Coder

Web: /rhythm → click "Analyze".

View Traffic Analytics

Select option 20 (Analytics)
Enter repo name (you must own the repo)
See 14-day data: views, unique visitors, clones, top referrers

Web: /analytics → enter repo name → click Load → bar chart visualization.

Note: GitHub only provides traffic data for repos where you have push access.

Switch Between Accounts

Select option 27 (Multi-account manager)
Add account: enter a label (e.g., "work") and paste a token
Switch: select a label from the list → active token changes instantly
Remove: delete an account by label

Tokens stored in ~/.gitpulse/accounts.json (chmod 600). No limit on accounts.

Create From Template

Select option 17 (Repo templates)
Choose template: Python package, Node.js app, ESP32 firmware, Static website
Enter repo name
GitPulse creates the repo with README, .gitignore, LICENSE, and starter files

Set Up SSH Keys

Select option 18 (SSH key manager)
Generate: creates an ed25519 key pair
Upload: sends public key to your GitHub account
Test: runs ssh -T git@github.com to verify

Edit Commit Timestamps

Select option 19 (Timestamp editor)
View: see author_date and commit_date for recent commits
Shift: move all commits by N hours/days (timezone fixes)
Randomize: scatter commits across business hours (privacy)

This rewrites git history — force push required.

Generate AI Summaries

Select option 22 (AI summaries)
AI Summary: generates plain-English repo overview. Requires openai pip package + API key (optional).
Magic Diff Storyteller: turns recent commits into a narrative. Uses pattern matching — no AI API needed.

Ambient Dashboard

Go to /ambient (or click "Ambient" in nav)
Opens fullscreen: clock, date, repo stats, live event feed
Auto-dims between 11pm–6am
Perfect on a second monitor or wall display

Use the Time Machine

Go to /timemachine/{repo-name}
Drag the slider to scrub through commit history
See: commit message, author, date, and full file tree at each point

Generate DNA Fingerprint

Go to /dna
Enter a repo name, click Generate
See a unique SVG pattern based on: language mix, commits, stars, creation date
Deterministic — same input always produces the same art

View Repo Graph

Go to /graph
All repos appear as nodes (sized by stars, colored by language)
Repos sharing a language are connected by lines
Drag nodes, zoom, explore the force-directed layout

Run From USB

Copy gitpulse/ folder to USB stick
(Optional) Put WinPython in portable/python/
Windows: double-click portable\run.bat
Linux: ./portable/run.sh
Add --web for web mode: portable\run.bat --web

Expose on LAN

Edit ~/.gitpulse/config.json: set "web_host": "0.0.0.0"
Run python gitpulse.py --web
Access from other devices at http://YOUR_IP:5000

⚠️ No authentication on the web UI. LAN only — do not expose to internet without a reverse proxy.
