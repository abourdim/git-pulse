Installation

Requirements

  • Python 3.8+ (tested 3.8–3.12)
  • requests library (auto-installed by installer)
  • GitHub token (or use demo mode)
  • Optional: openai (for AI summaries only)

Option A: One-Step Installer (recommended)

bash gitpulse.sh      # Select option 2 (Install)

The installer does everything in one step:

Updates package index (Linux)
Installs Python 3.8+ if missing
Installs pip if missing
Installs git if missing
Installs requests via pip
Copies all files to ~/.gitpulse/ (including the launcher itself)
Auto-creates gp alias in ~/.bashrc or ~/.zshrc

After install: delete the zip extraction folder — the gp alias points to ~/.gitpulse/gitpulse.sh and works from anywhere.

Option B: Manual Install

# 1. Unzip or clone gitpulse/
# 2. Install the dependency
pip install requests

# 3. Run
python gitpulse.py

Option C: Portable USB (zero install)

Copy the entire gitpulse/ folder to a USB stick
(Optional) Put WinPython in portable/python/ for zero-install Windows
Windows: double-click portable\run.bat
Linux: chmod +x portable/run.sh && ./portable/run.sh

Config is stored on the USB in portable/config/ — nothing touches the host machine.

Getting a GitHub Token

Go to github.com/settings/tokens
Click "Generate new token (classic)"
Name it GitPulse
Select scopes:
ScopeRequired?For
repo✅ YesAll repo operations
read:user✅ YesUser profile info
delete_repoOptionalDelete features
workflowOptionalActions monitor
Click Generate token, copy the ghp_... string
Paste when GitPulse asks, or set as env var: 
export GITHUB_TOKEN="ghp_your_token_here"

Where is my token stored?

  • File: ~/.gitpulse/config.json
  • Permissions: chmod 600 (owner-only)
  • Never sent anywhere except api.github.com
  • Never logged, shared, or cached

MSYS2 Specific

# Update first
pacman -Syu

# Install Python
pacman -S python python-pip

# Run installer
bash gitpulse.sh

Verify Installation

# Check Python
python --version       # Should be 3.8+

# Check requests
python -c "import requests; print(requests.__version__)"

# Run GitPulse
python gitpulse.py --demo    # Should show 17 demo repos
