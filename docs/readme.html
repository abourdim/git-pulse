GitPulse v6.0 - Noor

The complete GitHub repository manager - CLI + Web UI
Powered by workshop-diy.org

Quick Start

bash gitpulse.sh                    # Install
python gitpulse.py                  # CLI mode
python gitpulse.py --web            # Web UI
python gitpulse.py --demo           # Demo (no token)
python gitpulse.py --web --demo     # Web demo

Only dependency: requests - Python 3.8+
