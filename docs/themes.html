How i18n Works

  • Translation files: web/static/i18n/{en,fr,ar}.json — 89 keys each
  • Loader script: web/static/js/i18n.js — auto-loads on every page from localStorage
  • HTML tagging: data-i18n="key" on elements, data-i18n-attr="placeholder" for inputs
  • JS helper: t("key") for dynamic content
  • Live switch: changing language in Settings applies instantly (no page reload)
  • Persistence: saved to localStorage("gp_language"), applied before body renders (no flash)
  • RTL: Arabic triggers dir="rtl" on <html> — sidebar, breadcrumbs, text all flip

Adding a New Language

  1. Copy web/static/i18n/en.json to xx.json
  2. Translate all 89 values
  3. Add <option value="xx">Language Name</option> in settings.html
  4. If RTL: add val === "xx" to the dir check in header.html and settings.html
