Web UI

Starting

python gitpulse.py --web             # Normal
python gitpulse.py --web --demo      # Demo (no token)

Server: http://127.0.0.1:5000. Browser opens automatically. No token? Welcome page appears with Connect / Demo / Tutorial buttons.

Architecture

  • Server: web/server.py — Python http.server, zero deps
  • Router: web/router.py — URL dispatch with <param>
  • Templates: web/templating.py — {{var}}, {{for}}, {{if}}, {{include}}
  • Routes: web/routes/__init__.py — page + API handlers

File Workspace (v2.0+)

Full IDE-like file browser at /repo/{name}/files:

  • Tree panel — expandable folder tree with file sizes, filter search
  • Code viewer — syntax highlighting for 15+ languages (Python, JS, C/C++, Go, Rust, Ruby, Java, Shell, SQL, HTML, CSS, YAML, Dockerfile…)
  • Editor — edit any file in-browser, commit directly to GitHub
  • Preview — Markdown rendered live, split view (code + rendered)
  • Genius tools — README generator, template injector, TODO tracker, secret scanner, code search, image gallery
  • Upload / New / Delete — full file management

Internationalization (i18n)

Client-side translation system introduced in v6.0:

  • 3 languages: English, Français, العربية (with full RTL support)
  • 89 translation keys across 8 templates (74 tagged elements)
  • JSON files: /static/i18n/en.json, fr.json, ar.json
  • Loader: /static/js/i18n.js — reads gp_language from localStorage, applies on page load
  • Live switch: Settings → Language instantly reloads translations (no page refresh)
  • Tagging: data-i18n="key" for text, data-i18n-attr="placeholder" for input placeholders
  • JS helper: t("key") for dynamic content (toasts, generated HTML)

Syntax Highlighting (v4.0+)

The File Workspace code viewer uses a custom tokenizer-based highlighter:

  • 15+ languages with per-language keyword sets
  • Tokenizer — char-by-char state machine separates strings, comments, and code before coloring (prevents cross-contamination)
  • Colors: keywords (purple), strings (green), comments (dim italic), functions (blue), numbers (orange), decorators (pink), HTML tags (red), CSS properties (cyan)
  • HTML-safe — special path for HTML/XML files avoids tag/attribute corruption
