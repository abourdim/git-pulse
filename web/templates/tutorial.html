GitPulse v{{version}} — Tutorial

Complete guide to every feature · CLI + Web UI · 29 commands · 20 web pages

Quick Start

python gitpulse.py CLI mode

python gitpulse.py --web Web UI (opens browser)

python gitpulse.py --demo Demo mode (no token)

python gitpulse.py --web --demo Web demo

bash gitpulse.sh Full installer (MSYS2/Git Bash/Linux)

Only dependency: requests · Python 3.8+ · GitHub token with repo + read:user scopes

📦 Repos

📋List Repos CLI+Web

View all your GitHub repositories with visibility badges, language, stars, and last update. Sort by name, date, or stars. Filter by public/private/all.

CLI: option 1
Web: /repos

🔍Search Repos CLI+Web

Search across all repos by name, description, topic, or language. Instant results with matching highlights.

CLI: option 2
Web: search bar on /repos

📄Repo Details CLI+Web

Full view: description, language breakdown (%), recent commits, branches, clone URL, topics, license, creation date.

CLI: option 3
Web: /repo/{name}

✨Create Repo CLI+Web

Create a new repository with name, description, public/private toggle, and optional auto-init with README.

CLI: option 4
Web: POST /api/repo/create

🗑️Delete Repo CLI only

Permanently delete a repository. Requires double confirmation (type the name). Hidden in beginner mode.

CLI: option 5 (advanced)

✏️Edit Repo CLI Web

Change name, description, visibility (public/private), topics, default branch, homepage URL, wiki, issues, and archived status.

CLI: option 6 · Web: /repo/{name} → Edit button

📥Clone Repo CLI only

Clone any of your repos to a local directory. Uses git clone with your configured SSH or HTTPS.

CLI: option 7

🔀 Git Info

📝View Commits CLI+Web

List recent commits with SHA, message, author, and date. Configurable count (default 10). Color-coded by author.

CLI: option 8
Web: /repo/{name} (commits section)

🌿View Branches CLI+Web

List all branches with protection status. Shows default branch. Useful before merging or cleaning up.

CLI: option 9
Web: /repo/{name} (branches section)

CLI: option 10
Web: /backup

🏥Health Dashboard CLI+Web

Score every repo 0-100% based on: has README ✓, LICENSE ✓, .gitignore ✓, description ✓, topics ✓. Spot neglected repos instantly.

CLI: option 11
Web: /health

🔧Bulk Operations CLI only

Mass rename repos, toggle visibility (public↔private), bulk delete, add/remove topics across multiple repos at once.

CLI: option 12 (advanced)

📊Interactive Git Log CLI only

Rich git log with graph view, color-coded branches, author filters, date range filters. Navigate with keyboard.

CLI: option 13

View workflow runs across all repos. See status (pass/fail/running), duration, trigger event. Quick access to logs.

🛠️ Toolkit

📁Repo Templates CLI only

Create repos from boilerplates: Python package, Node.js app, ESP32 firmware, static website. Auto-generates README, .gitignore, LICENSE, CI config.

CLI: option 17

Generate ed25519 SSH keys, upload public key to GitHub, test connection. One command to set up SSH auth.

CLI: option 18

View, shift, or randomize commit dates. Shift all commits by N hours/days. Randomize within business hours. Useful for privacy or fixing timezone mistakes.

📊 Insights

📈Analytics & Traffic CLI+Web

14-day view counts, unique visitors, clone counts, and top referrers for any repo. Bar chart visualization in web UI.

CLI: option 20
Web: /analytics

📦Dependency Scanner CLI only

Scan requirements.txt, package.json, Cargo.toml for outdated packages. Flags known vulnerabilities. Checks latest versions.

🤖 AI / Summary

🧠AI Summaries CLI only

Generate a plain-English summary of any repo: what it does, tech stack, activity level. Uses OpenAI API (optional) or pattern-based fallback.

CLI: option 22

📖Magic Diff Storyteller CLI only

Turns recent commits into a narrative: "The project started with X, then the team focused on Y..." Pure pattern matching — no AI API needed.

CLI: option 22 → sub-menu

🛡️ Sentinel

🔴Danger Zone CLI+Web

Security scanner: detects 14 types of leaked secrets (GitHub tokens, AWS keys, Slack tokens, Stripe keys, private keys, etc.). Also checks risk indicators: missing .gitignore, public repo without license, unprotected default branch, repo >500MB.

CLI: option 23
Web: /danger

🏺Git Archaeology CLI+Web

Discover dead branches (>6 months without commits), large files (>1MB), TODO/FIXME/HACK comments scattered in code, stale PRs (>90 days), and empty repos.

CLI: option 24
Web: /archaeology

📂Smart Repo Grouper CLI+Web

Auto-categorize all repos into 10 types: Web App, Mobile, IoT/HW, API/Backend, Library, Data/ML, DevOps, Docs, Learning, Tool/CLI. Detection based on language, files, topics, name patterns.

CLI: option 25
Web: /grouper

💓 Rhythm

📉Commit Rhythm Analyzer CLI+Web

Analyzes your coding patterns across repos. Detects: peak coding hour, morning/evening/night percentages, weekday distribution, weekend coding %, burst days (5+ commits). Assigns a style: Night Owl 🦉, Early Bird 🐦, Evening Warrior 🌙, Dual Mode 🔄, Steady Coder ⚡.

CLI: option 26
Web: /rhythm

👤Multi-Account Manager CLI only

Add multiple GitHub accounts (personal, work, client). Switch between them instantly. Tokens stored securely in ~/.gitpulse/accounts.json (chmod 600).

CLI: option 27

🌐 Web-Only Features

⏰Git Time Machine Web only

Drag a slider through your commit history. See the commit message, author, date, and file tree at each point. Like scrubbing through a video of your repo's life.

Web: /timemachine/{repo}

🧬Repo DNA Fingerprint Web only

Generates a unique visual fingerprint (SVG) from repo characteristics: language mix, commit count, stars, creation date. Every repo gets a different pattern. Deterministic — same input always produces the same art.

Web: /dna

🕸️Repo Relationship Graph Web only

Force-directed graph visualization of all your repos. Nodes are repos (sized by stars), colored by language. Repos sharing a language are connected. Drag, zoom, explore.

Web: /graph

📡Live Collaboration Radar Web only

Real-time feed of GitHub events: pushes, PRs, issues, stars, forks happening on your repos. Auto-refreshes every 30 seconds. See who's interacting with your code.

Web: /radar

🎤Voice Control Web only

Click the microphone and speak: "list repos", "health check", "danger scan", "rhythm", "dashboard", "settings". Uses browser Speech Recognition API (Chrome/Edge).

Web: /voice

🌙Ambient Dashboard Web only

Full-screen always-on display: clock, date, repo stats (total, public, private, stars), live event feed. Auto-dims between 11pm–6am. Perfect for a wall monitor or side screen.

Web: /ambient

🌍 Modes & Languages

🐣Beginner Mode

8 menu items with friendly labels: "projects" instead of "repos", "download" instead of "clone". Dangerous features (delete, bulk delete) are hidden. Perfect for new users.

🔥Advanced Mode

29 menu items organized in sections: Repos, Git Info, Power Tools, Git Deep, DevOps, Toolkit, Insights, AI, Sentinel, Rhythm. Full technical terminology. All features unlocked.

🇬🇧English · 🇫🇷Français · 🇸🇦العربية

Full i18n with 3 languages. Arabic includes RTL layout support. Change language anytime from Settings. Web UI adapts direction automatically.

💾 Portable & Demo

🔌USB Portable Mode

Run from a USB stick with no installation. Config stored on the stick, not on the host machine. Works on Windows (run.bat) and Linux (run.sh). Optionally embed WinPython for zero-install Windows.

Windows: portable\run.bat
Linux: portable/run.sh

★Demo Mode

Try every feature without a GitHub token. 17 realistic sample repos spanning IoT, web, ML, mobile, and hardware projects. Mock data for health, security, analytics, and events. Repos can be "created" and "deleted" in-session (resets on restart).

python gitpulse.py --demo
Web: click "Try Demo" on welcome page
